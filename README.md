# UNSLEPT — concept 01

Сайт-презентация вымышленного концепт-кара. Портфолио-демо, не официальный сайт автопроизводителя.

## Запуск

```bash
npm install
npm run dev
```

## Медиа машины

| Файл | Что это |
|---|---|
| `public/car/turntable.mp4` | вращение кузова в герое, 1920×1080, 5 с, 6.3 МБ |
| `public/car/night.png` | ночной кадр в секции экстерьера, 187 КБ |

Пути прописаны в `src/config.ts`. Чтобы заменить видео, положи новый файл под тем же именем — вёрстку трогать не нужно. Если появится версия в WebM, добавь её в тот же объект: браузер сам выберет более лёгкий формат.

Видео весит 6.3 МБ, и это ощутимо на мобильном интернете. Сжатие требует ffmpeg, которого в системе пока нет.

Студийный фон в видео светлый, поэтому в CSS края кадра растворяются в тёмной странице маской и слегка притемняются фильтром. Если однажды сделаешь рендер на тёмном фоне, маску можно убрать.

Автоплей на iPhone работает только для беззвучного видео, поэтому `muted` и `playsInline` снимать нельзя. Если в системе включено «меньше анимации», видео не запускается само и получает кнопку плеера.

## Форма заявки

Пока `leadWebhook` равен `null`, форма копирует бриф в буфер обмена. Чтобы заявки падали в Discord, создай вебхук в настройках своего канала и впиши его в `src/config.ts`.

Учти: вебхук в коде фронтенда виден всем, кто откроет исходники страницы, и его можно спамить. Для личного демо это терпимо, для коммерческого сайта нужен серверный обработчик, например функция на Vercel.

## Деплой

Vercel, фреймворк определяется автоматически (Vite). Репозиторий можно держать приватным — ссылка на сайт всё равно работает.
