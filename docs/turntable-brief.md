# Техзадание: turntable UNSLEPT

Задача: кузов машины плавно поворачивается вокруг вертикальной оси на 360° и возвращается в исходный кадр. Зацикленное вращение без участия пользователя, работает как видео-фон.

**Текущий статус:** в герое стоит видео, сгенерированное в Kling — 1920×1080, 5 секунд, светлая студия. Этот файл остаётся техзаданием на случай, если понадобится версия чище: на тёмном фоне, с точным бесшовным стыком и меньшим весом.

## Требования к результату

| Параметр | Значение |
|---|---|
| Оборот | ровно 360°, бесшовный луп |
| Длина | 8 секунд |
| Частота | 30 кадров в секунду (240 кадров) |
| Разрешение | 1920×1080 |
| Камера | неподвижна, лёгкий наклон сверху (~10°) |
| Фон | прозрачный либо тёмная студия #04060a |
| Отдача | PNG-секвенция + MP4 (H.264) + WebM (VP9) |
| Права | коммерческое использование без ограничений |

Первый и последний кадр не должны совпадать полностью: последний кадр — это 359°, иначе на стыке лупа будет заметный подскок.

## Стилистика

Стилизованный неон, не фотореализм. Тёмный кузов, читаемый контур, светящаяся полоса по всей ширине передка, неоновая вставка в дисках. Палитра сайта: фон `#04060a`, циан `#00e5ff`, кислотный `#d6ff3a`.

На борту машины должна читаться надпись **UNSLEPT**.

## Если делаем сами в Blender

1. Модель: бесплатные CC0-машины — [Poly Pizza, бандл Quaternius](https://poly.pizza/bundle/Cars-Bundle-FE5IWe6OMk) в форматах FBX и GLB. На Sketchfab моделей больше, но там обязательно фильтровать по лицензии.
2. Поставить модель в центр координат, камеру — на расстоянии, слегка сверху.
3. Вращать сам объект по оси Z: ключ на кадре 1 = 0°, ключ на кадре 241 = 360°, интерполяция линейная. Рендерить кадры 1–240.
4. Движок EEVEE, не Cycles: минуты вместо часов.
5. Свет: две большие площадки по бокам плюс тонкая emission-полоса на передке.
6. Собрать видео: `ffmpeg -framerate 30 -i frame%04d.png -c:v libvpx-vp9 -b:v 0 -crf 33 turntable.webm`

Целевой вес видео — до 3 МБ, иначе на мобильном интернете герой будет грузиться слишком долго.
